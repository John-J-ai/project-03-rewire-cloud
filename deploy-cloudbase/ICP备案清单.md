# ICP 备案清单（个人 · 非经营性 · 上海）

> 只用于 REWIRE 云版静态站点的自定义域名备案。信息按 2026-11 公开口径整理；**最终以腾讯云备案系统和上海通信管理局实时要求为准**。
> 我（AI）能做的是把清单和步骤写清楚；**实名、人脸核验、短信核验必须由你本人完成**，我不能代你提交，也不建议你把身份证照片交给任何第三方代办。

## 一、先确认你有没有资格走 CloudBase 内备案

CloudBase 环境内办备案的三个准入条件（缺一不可）：

- [ ] 套餐为**个人版及以上**（免费体验环境不支持）
- [ ] 环境剩余有效期 **> 6 个月**
- [ ] 环境已开启「**云托管固定 IP**」

不满足的话，只能先用默认域名测流程，或者在腾讯云买一台轻量服务器/云主机走常规备案（多一笔服务器钱）。

## 二、材料清单

基础四件：

| 材料 | 说明 | 必须本人 |
|---|---|---|
| 居民身份证正反面 | 清晰、不反光；加水印写「仅限 ICP 备案使用」，透明半透明、别盖住文字 | 是 |
| 域名证书 | 域名注册商后台下载；**域名所有者须与备案主体一致**，且域名已完成实名认证 | 否（下载即可） |
| 手机号 + 邮箱 | 应急电话不能与主体电话相同，**不能是 170/171 虚拟号段** | 是 |
| 人脸核验 | 腾讯云 App 扫码；光线均匀、不戴眼镜、不逆光 | 是 |

上海额外注意：

- **非上海户籍个人备案不支持学生证**，需提供居住证/暂住证（或修改成证件地址所在地备案）。你如果在临港读大学但户籍不在上海，这一条大概率会卡住，先问清楚再买域名。
- 同一主体下**超过 5 个网站**才需要《网站建设方案书》；你只有 1 个站点，用不上。
- 若**未满 18 周岁**（满 16 不满 18），部分管局要求劳动就业或收入证明，上海需单独向接入商确认。

## 三、填表避坑

- **网站名称**：个人备案不能含「官网 / 公司 / 企业 / 商城 / 论坛 / 下载站」等词，也别用过于宽泛的「XX 网」。建议「姓名 + 小站」这类朴素命名。
- **网站描述**：写具体，例如「记录个人学习前端开发、数据可视化与隐私保护工具的笔记站点」。不要写「个人网站」四个字，也不要出现blog/论坛/交易等易触发前置审批的词。
- **前置审批项**：选「无」。本站点没有新闻、出版、教育、医疗、视听等特殊内容。
- **域名所有者 = 备案主体**：不一致会被直接驳回，包括用家人名义买的域名。

## 四、流程与时间线

1. 填主体信息（姓名、身份证号、有效期、通信地址、应急电话）
2. 填网站信息（名称、域名、语言、描述、前置审批）
3. 上传证件 + App 人脸核验 → 自动生成《真实性核验单》→ 电子签名
4. 服务商初审：通常 1–2 个工作日，可能电话回访，问「是否本人备案 / 网站用途」
5. **工信部短信核验：提交后 24 小时内完成**，超时作废重来
6. 上海管局终审：公开口径约 7–10 个工作日（区间 1–20 天，以实际为准）
7. 通过后拿到备案号 → 在网站页脚展示并链接工信部 → 回 CloudBase 绑定自定义域名

## 五、备案期间站点状态

- 备案未通过前，自定义域名不能对外服务；默认域名仍可用于测试。
- 通过并绑定后，用 `https://你的域名/index.html?demo=1` 打开验证。
- 演示模式不会连接真实 Supabase，适合作为对外展示入口；真实云同步需使用者自己填 anon key。

## 六、我建议你现在的顺序

1. **先走路线 A 把 `tcb deploy` 跑通**，确认站点在国内能打开（`?demo=1`）。
2. 再确认户籍/年龄/套餐条件是否满足；不满足就别买域名，省下年费。
3. 条件齐了再买域名 + 提交备案，备案期间站点先用默认域名。
4. 备案通过后，把正式链接放进作品集；默认域名的中间页和限流不适合当门面。

## 七、合规边界

- 个人备案 = 非经营性，站点不得有在线交易、付费、广告变现。
- 匿名基准收集的是八维分数与完成率，仍应在页面里明确告知参与者（已在应用内写明）。
- 备案主体、域名所有者、实际运营者应一致；借别人身份备案属于违规。
